                           II. DATA COLLECTION (THU THẬP DỮ LIỆU)
================================================================================

1. Phương pháp thu thập:
   - Web scraping sử dụng BeautifulSoup và requests
   - Đa luồng (multi-threading) để tăng tốc độ
   - Anti-bot detection với user-agent rotation và delays
   - Lưu trực tiếp vào MongoDB Atlas

2. Chi tiết từng nguồn:

   a) VnExpress (scrape_vnexpress.py):
   - 16 trang × 7 chuyên mục = ~1000 bài báo
   - Phân trang: category-p{page}.html
   - Selector: h2/h3.title-news > a
   - Chỉ 3 trang đầu tiên được gán nhãn category

   b) Tuổi Trẻ (scrape_tuoitre.py):
   - 34 trang × 7 chuyên mục = ~1600 bài báo  
   - Phân trang: category/trang-{page}.htm
   - Selector: div.box-category-item > h3 > a.box-category-link-title
   - Chỉ 8 trang đầu tiên được gán nhãn category

   c) Thanh Niên (scrape_thanhnien.py):
   - 30 trang × 7 danh mục = ~4140 bài báo
   - AJAX endpoint: /timelinelist/{category_id}/{page}.htm
   - Selector: div.box-category-item > a.box-category-link-title
   - Chỉ 7 trang đầu tiên được gán nhãn category

3. Cấu trúc dữ liệu thu thập (21 fields):
   - article_id, title, article_content, description, url
   - site, author, publish_date, category, category_url
   - tags, featured_image, featured_image_alt, images
   - video_url, meta_description, meta_keywords, og_tags
   - paragraph_count, word_count, estimated_read_time_minutes, subheadings

4. Kết quả thu thập:
   - Tổng cộng: ~13,159 bài báo
   - Dữ liệu được lưu trong MongoDB Atlas collection: "news_data_collection"
   - Phân phối theo các trang báo và thể loại

================================================================================
                        III. PREPROCESSING (TIỀN XỬ LÝ)
================================================================================

1. Cleaning (Làm sạch dữ liệu):
   - 01_handle_missing_values_fast.py:
     * Xử lý giá trị NULL/None trực tiếp trong MongoDB
     * author = "None" thay vì NULL
     * tags = [category] thay vì []
     * featured_image_alt = title nếu NULL
     * images = [] thay vì NULL
     * Batch processing cho hiệu suất cao

   - 02_handle_invalid_noise.py:
     * Loại bỏ dữ liệu không hợp lệ, nhiễu

   - 03_detect_remove_outliers.py:
     * Phát hiện và loại bỏ outliers

   - 04_normalize_language_noise.py:
     * Chuẩn hóa nhiễu ngôn ngữ

2. Integration (Tích hợp):
   - 01_merge_field.py: Gộp các trường dữ liệu liên quan
   - 02_remove_unnecessary_columns.py: Loại bỏ cột không cần thiết
   - 03_normalize_schema.py: Chuẩn hóa schema

3. Transformation (Chuyển đổi):
   - 01_lowercasing.py: Chuyển thành chữ thường
   - 02_tokenization.py: Tokenization văn bản tiếng Việt
   - 03_stopword_removal.py:
     * Xóa stopwords tiếng Việt (56+ từ)
     * Xóa dấu câu và ký tự đặc biệt
     * 2-layer filtering: stopwords + regex validation
     * Token reduction: ~30-40% số token bị loại bỏ

4. Encoding (Mã hóa):
   - 01_label_encoding.py: Mã hóa labels (0-6 cho 7 thể loại)
   - 02_tfidf_vectorization.py: Vectorization TF-IDF
   - 03_generate_site_onehot_mapping.py: Tạo mapping cho site one-hot
   - 04_update_site_onehot_field.py: Cập nhật trường site one-hot

5. Kết quả preprocessing:
   - Dữ liệu sạch và chuẩn hóa
   - Token hóa và loại bỏ stopwords
   - Mã hóa labels và features
   - Lưu trong collection: "news_data_preprocessing"

================================================================================
                         IV. PROCESSING (XỬ LÝ PHÂN TÍCH)
================================================================================

1. Data Split (Chia dữ liệu):
   - export_and_split.py:
     * Train/Validation/Unlabeled split
     * Train: ~2,000 samples (có labels)
     * Validation: ~500 samples (có labels)  
     * Unlabeled: ~9,855 samples (chưa có labels)

2. Feature Engineering (TF-IDF + SVD):
   - feature_engineering_tfidf_svd.py:
     * TF-IDF Vectorizer:
       - max_features: 3000
       - ngram_range: (1, 2)
       - min_df: 2, max_df: 0.8
       - sublinear_tf: True
     * TruncatedSVD:
       - n_components: 300
       - Giảm chiều từ 3000 → 300
       - Tổng explained variance: ~70-80%
     * Site one-hot encoding: 4 dimensions
     * Final feature shape: (n_samples, 304)

3. Base Model HPO (Hyperparameter Optimization):
   - train_base_model_hpo.py:
     * Tìm kiếm hyperparameters tối ưu
     * Mô hình base: Logistic Regression hoặc Random Forest

4. Self-Training Loop:
   - self_training_topk.py:
     * Semi-supervised learning
     * Sử dụng model đã train để gán nhãn cho unlabeled data
     * Top-K selection với confidence threshold
     * Lặp lại quá trình nhiều iterations
     * Final model calibration
     * Kết quả: Model có khả năng phân loại 9,855 samples mới

5. Processing Pipeline Summary:
   - Input: 13,159 documents (preprocessed)
   - Output: Trained model + predictions cho toàn bộ dữ liệu
   - Features: TF-IDF + SVD + Site one-hot (304 dimensions)
   - Model: Calibrated classifier với high confidence
